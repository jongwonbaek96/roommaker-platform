# 1. 스토리 바이블

## 1-1. 세계 설정
- **노선**: 수도권 외곽 가상의 순환선 "**서환선(西環線)**". 12개 역 순환. 오늘 밤 플레이어가 탄 것은 **7788편성 막차** — 시간표상 존재하지 않는 23:57 열차.
- **사고**: **1996년 2월 17일**, 서환선 열차가 **명원(明原)터널** 진입 직전 탈선. 승객 27명 전원 사망, 승객을 구하려 객차로 되돌아간 **차장 임관수(당시 51세)** 1명 순직. 이후 명원역은 폐역, 노선이 우회 개편되며 '두물역'이 신설됨. 기사마다 사망자 수가 26/27/28로 다르게 보도됨(신원미상 1인 제외 표기 / 승객만 / 승무원 포함).
- **열차의 진실**: 7788편성은 매일 밤 사망자 27명을 태우고 서환선을 돌며 명원역으로 향하는 열차. 오늘 밤 플레이어(살아있는 신입 차장)가 근무표를 착각하고 3분 이른 이 열차에 올라탔다.
- **'그 승객'**: 임관수. 명단에 없는 유일한 존재(승무원이므로). 8호차에서 출발해 플레이어가 방심할 때마다 한 칸씩 다가온다. 목적은 습격이 아니라 경고 — "이 열차에서 내려야 한다." 그러나 이 사실은 파이널까지 절대 노출하지 않는다. 접근 연출은 끝까지 순수한 공포로 유지.

## 1-3. 챕터별 시나리오 (연출 스크립트)

### 프롤로그 「23:57」
- (검은 화면, 타자기 텍스트) *"첫 단독 승무. 00시 정각, 서환선 막차."* → 승강장 씬. 전광판: `막차 00:00` — 그런데 23:57에 열차가 미끄러져 들어온다. *"…일찍 왔네."* (복선①, 코멘트는 이 한 줄만)
- M01~M03 수행 → 발차. 무전은 잡음 속 "…출발…하세요…"만. 창밖이 어둠에 잠기며 타이틀 로고 `막차` 표시.
- 튜토리얼 토스트 2개만: "행동이 없으면 열차가 어두워집니다" / "[뒤칸 확인]으로 뒤를 볼 수 있습니다". 이후 시스템 설명 없음(어려움).

### 챕터1 「한내역」 — 업무는 정상이다
- 평범한 검표·차량 점검. 공포는 소등과 소리로만. 챕터 말미 Q09에서 "이 열차, 시간표에 없다"는 위화감의 씨앗.
- 종료 연출: 8호차 형광등이 나간다. 안내방송(정상): "다음 역은 구름다리역입니다."

### 챕터2 「구름다리역」 — 하나가 더 있다
- Q12에서 탑승 인원이 명단보다 1명 많다는 계산이 나옴 → 이때부터 하단 객차 미니맵에 소등 칸이 표시되기 시작(시스템 인지와 서사 인지의 동기화).
- 할머니 승객(M13)의 한 마디: "우리 아들도 차장이었는데." (복선②)

### 챕터3 「은계역」 — 이 열차의 목적지
- 위조표 감별(M17) 중 검표기 라이트에 비친 진짜 표들의 목적지가 전부 **명원**. 운행일지(Q18)로 1996 사고의 존재를, 차장 가방(M19~Q21)으로 임관수의 이름을 알게 됨. 단, "그래서 그 승객이 누구다"는 연결은 짓지 않는다 — 플레이어가 스스로 잇게 남겨둠.
- 챕터 말미부터 안내방송 오염 시작: "다음 역은… 명원, 명원역입니다." (노선도에 없는 역)

### 챕터4 「갈뫼역」 — 열차는 멈추지 않는다
- 점검 업무가 점점 '열차를 멈추기 위한' 시도로 바뀜. 기사 스크랩(Q25)으로 사망자 수의 진실(승객 27+차장 1)에 도달. 지붕 점검(M26)으로 무전 안테나를 고치지만 들리는 건 더 선명해진 잡음뿐.
- 종료 연출: 창밖에 눈이 내리기 시작한다. 1996년 2월 17일도 눈이 왔다(기사 사진과 동일 — 눈치챈 사람만 아는 복선③).

### 챕터5 「청단역」 — 내릴 수 없는 계산
- Q29: 도착 시각을 계산하면 00:56 — 그러나 상단 시계는 밤새 **00:47에 멈춰 있었다**(코멘트 없음, 관찰자만 발견). M31: 운전실은 비어 있고 자동운전 장치의 목적지는 `명원`. 수동 전환은 거부된다 — *권한: 차장 임관수*.
- Q32 "명원" 입력 순간 전 객차 1초 완전 소등 → 재점등. 그가 **2호차**까지 와 있다.

### 파이널 「종점 직전」
- M33: 남은 배터리로는 7칸만 밝힐 수 있다. 어느 칸을 어둠에 내줄지 플레이어가 직접 고른다 — 그 칸을 통해 그가 승무실 문 앞까지 온다.
- Q34: 명단 마지막 장. `승무: 차장 ______`. 플레이어가 서명했던 이름이 아니라 **임관수**가 인쇄되어 있다. 이름을 입력하는 순간 **리빌 몽타주**(1-4 참조).
- M35: 승무실 문에 노크 소리. 문 레버에 손을 올린 채 최종 선택.

## 1-4. 리빌 몽타주 (Q34 정답 직후, 15초 자동 연출)
플래시백 컷 6장이 심박 리듬으로 지나간다 — ① 23:57, 3분 이른 열차 ② 승객들의 구형 동전 ③ 갈수록 연도가 과거로 가는 광고판 ④ 밤새 00:47에 멈춰 있던 시계 ⑤ 명단 승객 27명 = 1996 사고 사망자 수 ⑥ 근무표의 진짜 막차: 00:00. 마지막 자막: *"나는, 타면 안 되는 열차에 탔다."* 그리고 노크 소리.

## 1-5. 엔딩 전문

**진 엔딩 「환승」** — [문을 연다]
문이 열리면 낡은 제복의 차장이 서 있다. 처음으로 얼굴이 보인다 — 무섭지 않은, 피곤한 얼굴. 그가 승강장 쪽을 가리킨다. 열차가 어느새 어느 역에 서 있다. 내리는 순간 뒤에서 목소리: *"수고했어, 신입. 첫차 타고 가."* 돌아보면 문이 닫히고, 7788편성이 어둠 속으로 미끄러진다. 전광판: `첫차 05:31 — 곧 도착`. 하늘이 밝아온다. (리포트 화면: 잡힘 횟수·힌트·플레이타임 / 히든 달성 시 승무일지에 도장 "무사고 승무" 추가)

**배드 엔딩 「종점」** — 60초 버티기
노크가 멎는다. 안도한 순간 열차가 감속한다. *"명원, 명원역입니다. 내리실 문은 왼쪽입니다."* 승객 13명이 일제히 일어나 이쪽을 본다. 문이 열린다. 어둠뿐인 승강장에서 손들이 들어온다 — *"같이 내려요. 다 왔어요."* 암전. `계속하기 → 23:57` (오토세이브는 파이널 직전으로 롤백, 재도전 가능)

# 2. 핵심 시스템 상세

## 2-1. 접근 시스템 `ApproachSystem` (GazeSystem 변형)
게이지 0~100. **게이지 = 그 승객의 위치**로 즉시 번역된다.

| 단계 | 게이지 | 그 승객 위치 | 시각 연출 | 청각 연출 |
|---|---|---|---|---|
| 0 | 0~19 | 8호차 | 미니맵 전체 점등 | 주행 룸블 + 레일 클랙 |
| 1 | 20~39 | 8호차 소등 | 미니맵 8번 칸 어둡게, 형광등 '팅' | 소등음, 먼 문 여닫힘 |
| 2 | 40~59 | 6호차 | 6·7번 칸 소등, 창 반사에 스침 | 느린 발소리(리버브 큼) |
| 3 | 60~79 | 4호차 | 절반 소등, 화면 가장자리 비네팅 | 발소리 선명, 저역 드론 |
| 4 | 80~99 | 2호차·연결통로 | 통로 창에 실루엣 고정, UI 미세 떨림 | 유리 너머 숨소리, 심박 |
| 5 | 100 | 승무실 문 | 점프스케어(문 손잡이 회전) | 스팅어 |

**수치 (어려움)**
- 유의미 행동 없음 12초 경과 시 상승 시작, 기본 **+2.5/초**
- 챕터 보정: 챕터 n에서 상승속도 ×(1 + 0.05n)
- **조명 감쇠**: 점등된 객차 1칸당 상승속도 −8% (최대 5칸 −40%) — 조명이 곧 방어
- 유의미 행동 1회 −8 (2초 내 중복 무효) / 문제 1개 해결 −40 + 12초 유예 / 3연속 오답 +15 / 힌트 +20
- 읽기 구간(시나리오 텍스트·리빌)은 동결
- **잡힘**: 점프스케어 → 현재 챕터 시작 복귀, 이번 챕터 단서 1개 재획득, 누적 카운트. 3회 누적마다 승무실 소품이 영구 변화(모자가 걸려 있던 자리가 비는 등)

## 2-2. 뒤칸 확인 `LookBackSystem`
- 상시 버튼 [뒤칸 확인] — 탭하면 1.2초 카메라 회전 연출로 연결통로 창 오버레이 진입
- 단계 0~1: 빈 통로 (게이지 −15) / 단계 2~4: **그가 통로 저편·중간·유리 앞에 서 있다** → 버튼이 [검표기 플래시]로 전환, **홀드 2.5초** 성공 시 한 칸 후퇴(해당 단계 하한으로 하락). 0.8초 미만에 떼면 +10
- 단계 4에서 실패 시 즉시 잡힘 판정
- 쿨다운 10초 (버튼에 원형 쿨다운 링), 페이크 연출 10%(창밖 터널 조명이 사람처럼 스침)
- 확인 중에도 정차 90초 타이머·미션 제한시간은 계속 흐름

## 2-3. 조명·배터리 `PowerSystem`
- 배터리 0~100, 시작 60. **점등 칸 1개당 −2/분**
- 조작: 승무실 조작반의 8칸 스위치(개별) + 미니맵 탭(바로가기)
- 충전: 미션 보상(+15~30, 총 +95 설계) / M24 이후 충전소 1회 +30
- 배터리 0 → 전 칸 소등, 상승속도 최대치. 파이널 M33은 잔량이 정확히 7칸분이 되도록 수렴 설계(획득을 다 해도 8칸분에 1칸 모자람)

## 2-4. 정차/주행 사이클
- 각 챕터 = 주행부(제한 없음) → **정차 90초**(정차 한정 미션: M05 등) → 발차
- 정차 한정 미션을 90초 내 실패 시: 40초 '재정차 대기'(문이 안 열린 채 정차 — 게이지 취약 구간) 후 재시도
- 정차 30초 전 차임 2회, 10초 전 LED 점멸 — 시간 압박의 리듬화

## 2-5. 힌트
- 승무 가방의 「승무원 필휴 매뉴얼」 책자. 힌트 버튼을 누르면 책이 저절로 펄럭이며 해당 문제 페이지가 펴짐(연출) — 전체 3회, 사용 즉시 게이지 +20
- 3회 소진 후 버튼은 "더 넘길 페이지가 없다"로 비활성

## 7-4. 자동 검증 계획 (jsdom 플레이스루)
1) 35문제 전체 도달·해결 가능 경로 시뮬레이션(정답 주입) 2) 게이지 극값 전이(0/100, 잡힘→복귀→단서 재획득) 3) 배터리 수렴(파이널 클램프 = 7칸분) 4) 미니맵 해금 전 잠김 보장 5) Q34에 playerName 입력 시 거부 분기 6) 양 엔딩+히든 조건 도달 7) localStorage 라운드트립. — ward-306 검증 스크립트 포맷 재사용.

## 7-5. 성능·접근성
- 파티클 상한 120, 필터 애니메이션은 transform/opacity만 사용(리플로 금지)
