# 초대받지 않은 손님 (Uninvited) — 스토리·세계관·엔딩 [초안 v0.1]

> 그는 앞을 못 본다. 대신, 소리를 본다.

- **장르**: 공포 / 방탈출 / 정적(靜寂) 압박형
- **로그라인**: 폭우로 고립된 외딴 별장. 앞을 보지 못하는 연쇄살인마가 **소리로 사냥**한다. 당신이 오래 손을 멈추면 심장·숨소리가 새어나가 위치가 발각되고, 그가 방으로 좁혀 온다. 반대로 어떤 미션은 일부러 소음을 내야 풀린다 — 소리를 언제 죽이고 언제 지를지가 생존을 가른다.
- **러닝타임**: 2시간+ / **난이도**: 어려움
- **분량 목표**: 33 챌린지 (미션 24 · 문제 9 ≈ 73:27) — 본 초안엔 대표 15개 수록

## 핵심 시스템 — 정적 게이지 (Silence)

위협이 "행동 없는 시간(=새어나가는 생체 소음)"에 반응한다.

- **발각 게이지(0→100)**: 입력이 없는 매 초 상승(심박음이 점점 커지는 청각 UI). 상호작용 시 잠깐 정지, 정답 시 큰 폭 하락.
- **거리 4단계**: 아래층 → 계단 → 복도 → 문 앞. 그는 손잡이를 더듬고, 벽을 두드려 반향을 읽는다.
- **소음 미션의 역설**: 특정 잠금은 '소리'로만 열린다(오르골·괘종·라디오). 이때 발각 게이지가 급상승 → 풀자마자 '숨죽이기(입력정지 허용 안전창)'로 넘겨야 함.
- **되돌리기**: 구역마다 1회용 "빗소리 스위치"(창문 열어 빗소리로 생체음 가림) → 게이지 -40.
- 100 = 급습 → 게임오버, 구역 체크포인트로.

## 세계관

3년 전 이 지역에서 실종된 다섯 사람. 별장 주인 '**청각의 사냥꾼**'은 사고로 시력을 잃은 뒤 청력에 집착하며, 소리를 낸 자만 '초대 손님'으로 여겨 사냥한다. 플레이어는 실종된 마지막 피해자의 가족으로, 단서를 좇아 별장에 잠입했다가 폭우로 고립된다.

## 맵 (5구역)

1. **현관·거실** — 튜토리얼, 소음/정적 메커니즘 학습
2. **주방·식료품고** — 도구·무게·타이밍 미션
3. **음악실** — 소리 기반 문제 밀집(역설 구간)
4. **주인의 침실·서재** — 피해자 기록, 진실
5. **지하실** — 클라이맥스, 탈출로 확보 + 엔딩

## 엔딩 (3분기)

- **A. 탈출**: 폭우 속 차고 열쇠로 혼자 빠져나간다.
- **B. 대치(진엔딩)**: 그의 보청 장치를 역이용해 하울링으로 제압 + 피해자 유품 5개 회수 → 경찰 도착.
- **C. 사냥(배드)**: 발각 누적/오판 → 여섯 번째 손님이 된다.
