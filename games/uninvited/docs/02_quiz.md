# 초대받지 않은 손님 — 문제·미션·정답·힌트 [초안 v0.1]

표기: **[미]** 미션 · **[문]** 문제. `▶정답:` 제작용(비공개).

## 구역 1 — 현관·거실 (3)

1. **[미]** 신발장에서 피해자 신발 사이즈 순으로 정렬 → 숨은 열쇠(정적 유지 튜토리얼).
2. **[문]** 벽시계·괘종의 시각 차이로 '멈춘 시간' 계산 → 금고. ▶정답: 시차 4자리
3. **[미]** 삐걱대는 마루판을 밟지 않고 지나 도구 회수(소음=발각 학습).

## 구역 2 — 주방·식료품고 (4)

4. **[미]** 접시 무게를 저울에 맞춰 균형 → 찬장 잠금 해제(오래 멈추면 그릇 흔들림 소음).
5. **[문]** 통조림 유통기한을 규칙대로 배열 → 코드. ▶정답: 날짜 배열값
6. **[미]** 물 끓는 소리로 그의 주의를 다른 방으로 유인(소음 미션 → 직후 숨죽이기).
7. **[문]** 레시피 계량 단위 환산 합. ▶정답: 총량

## 구역 3 — 음악실 (3, 역설 구간)

8. **[미]** 오르골 태엽을 지정 마디만큼 감아 선율 완성 → 비밀 서랍(발각 급상승).
9. **[문]** 악보 계이름을 숫자로(도=1…) 변환한 4자리. ▶정답: 계이름 매핑
10. **[미]** 라디오 주파수를 맞춰 암호 방송 청취 → 다음 코드 획득 후 즉시 볼륨 차단.

## 구역 4 — 침실·서재 (3)

11. **[미]** 피해자 유품 5개 중 3개 회수(엔딩 B 진행) — 서랍 순서 퍼즐.
12. **[문]** 일지의 '방문객 명단' 치환 암호 해독 → 지하 열쇠 번호. ▶정답: 치환 결과
13. **[미]** '빗소리 스위치' 확보 — 창문 걸쇠 3단 해제.

## 구역 5 — 지하실 (2)

14. **[미]** 보청 장치 배선을 재연결해 하울링 트랩 설치(엔딩 B 조건).
15. **[문]** 차고 셔터 콘솔 — 앞 구역 코드 종합 입력. ▶정답: 종합값

> **확장 메모**: 소음↔정적 전환 미션을 구역마다 1개씩 더 배치해 33개로. 음악실에 '반향 위치추적' 문제, 지하에 '숨 참기 QTE' 추가 예정.
